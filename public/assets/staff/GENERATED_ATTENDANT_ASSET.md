# Generated arcade attendant cutout

File: `arcade-attendant-cutout.webp`

This transparent, photorealistic staff cutout was generated for Claw Chaos
using OpenAI image generation. It is used only as a visual sprite. It has no
collision body and does not affect staff service, prize restocking, or game
physics.

The source render is 1024 × 1536 pixels with an alpha channel. The production
asset is encoded as WebP with alpha transparency to keep download size small.

The character design uses a white collared blouse, pink trim and bow, charcoal
waistcoat, knee-length skirt, dark tights and low-heel shoes. The welcoming
open-hand pose presents toward the cabinet. The Three.js sprite faces the
active camera automatically.
